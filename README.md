# 钟乳石洞穴微环境巡测

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在`data/db.json`，后续可以继续增量迭代。

## 冷箱转运

洞穴水样从采样到送实验室的冷链分段追踪，解决"换车交接只有最终温度、查不出哪一段断链"的问题：

- **样品瓶**：每瓶绑定样点与采样员，登记采样时刻。
- **冷箱**：同一冷箱存在未结束转运时，不能装别批样品。
- **到站交接**：每站登记温度、接收人、封条；温度超出 2~8℃ 或封条破损自动转待复检，并须由另一位巡测员复测（复测人不能与接收人相同）。
- **更正重算**：采样时刻、样点或封条更正后，关联交接的复核结论按新值重算；封条更正会作废原复测结论。所有旧记录进存档，随时可查。
- **转运看板**：按等待时间排列（未送达在前），展示每瓶当前所在站点、每段交接耗时，问题交接以 ⚠ 标出。

代码按职责分离承载：

| 职责 | 位置 |
| --- | --- |
| 判定（温度/封条 → 结论、重算） | `lib/judgment.js` |
| 存档（更正前旧记录快照） | `lib/archive.js` |
| 页面入口（看板与表单） | `public/chain.js` |
| 接口挂载 | `server.js` 的 `/api/chain/*` |
